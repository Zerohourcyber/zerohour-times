# Screenshots

These are **not generated by CI** and are not committed automatically. They are
captured by hand from **demo mode**, never from a real instance.

## Why demo mode, always

A real dashboard shows the companies you are pursuing, the roles you have applied
to, your compensation target, your stated limits, and the questions you plan to
ask a specific recruiter. Published on a public repository, that is searchable,
permanent, and tied to your name while you are interviewing. A screenshot of your
own salary target sitting next to an employer's posted band is a negotiating
position given away for free.

Demo mode renders the identical layout from invented data — invented employers,
invented postings, invented sources, all pointing at `example.com`. There is no
visual advantage to using real data, and a real cost.

## Capture

Start the demo:

```bash
docker compose -f docker-compose.demo.yml up --build
```

Open <http://localhost:8099>. Set the browser to roughly 1550px wide for the
front page, and ~800px for the detail shots so the tables are readable. Use a
light theme.

Take six:

| File | What to capture |
|---|---|
| `newspaper.png` | The front page from the masthead down through the first few notices. This is the hero image in the project README — the one that matters most. |
| `assessment-eligibility.png` | Expand **Northwind Analytics — Senior Technical Program Manager**. Capture the SCORES/PREFERENCE/VERDICT lines, the Eligibility table and the Core Competencies table. |
| `assessment-reasoning.png` | Same card, scrolled: Qualification, Transferable Experience, Preference Fit, Career Direction. |
| `assessment-gaps.png` | Same card, scrolled: Compensation, Workload Indicators, Gaps / Risks with its Confirmed Gaps / Not Documented / Questions for Recruiter split. |
| `research-company.png` | **Our Correspondent Reports** — sections 1 and 2, company stage and what the role actually does. |
| `research-questions.png` | Same report — sections 3 to 5, published compensation data, ambiguous qualifications, and the four questions to ask. |

Save them here, then uncomment the image block near the top of the project
`README.md`.

## Before you commit a screenshot

Check the image itself, not the page you think you captured:

- No real employer name anywhere in frame.
- No real salary figure, and no line of the form "the candidate's stated target
  of ...".
- No browser tab, bookmark bar, profile avatar or notification showing anything
  personal.
- The URL bar reads `localhost`, not a Tailscale address or a hostname.

The fictional names you *should* see are Northwind Analytics, Vance Maritime
Group, Halden Instruments, Calder & Roe and Ashgrove Health. If you see anything
else, you captured the wrong instance.
